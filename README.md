# CHERRY LINE — repository package

## Files
- `index.html`: portfolio structure and contact links
- `styles.css`: visual design and responsive styles
- `app.js`: rendering, media management, and carousel logic
- `Media/`: add the original photo/video files here

## Sport Content and School Content
Sport Content and School Content each use their own independent preview carousel. The active media is centered, with previous/next previews on either side, arrows, dots, and a counter. About retains its separate four-photo carousel and its existing sizing.

## Publish on GitHub Pages
Upload the contents of this folder to the root of your repository. Keep `index.html`, `styles.css`, and `app.js` together at the root. Keep media files inside the case-sensitive `Media/` folder.
